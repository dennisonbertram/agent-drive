# Redundancy and information architecture

Source catalog plus live baseline evidence; recommendations, not implemented changes.

- **Duplicate creation paths:** top New drive and first-drive CTA open the same dialog. Keep both as discoverable entry and repeat-use shortcut; no parallel implementation.
- **Usage / Billing:** storage and activity appear in both. Keep the operational workspace view separate from money, period estimates and write caps. Do not merge simply because numbers recur.
- **Encryption copy:** sidebar, topbar and key-required banner repeat related facts. The banner explains an actionable key requirement; the sidebar and status mark product trust. Consider density only after mobile pixel review, not a blanket deletion.
- **CLI / MCP:** intentional automation interfaces, not duplicate browser upload implementations. Do not remove one or invent upload controls to shorten a catalog path.
- **Navigation:** Files and common tabs are direct on desktop. At 375px later destinations are offscreen in a horizontal strip. Evaluate an explicit responsive layout in visual review. No global-search feature exists; loaded-only filtering must remain honestly scoped.

No destructive safety step is considered redundant merely because it adds an action.

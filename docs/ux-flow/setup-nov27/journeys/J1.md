## 4. Clarity issues

- **"Pairing code", "code", "verification code", "check that the code matches"**: four names for two codes. CLI line 2 says "Check that the code matches"; the page says "Does this code match your terminal?" next to a big code that is not the one to type, and a field labelled "Verification code" (W/009 Flow Log; `W/016/screenshots/step-1.png`). Suggested names: "Pairing code" (compare, shown on both) and "Secret code" or "Approval code" (type). Pick two words and use them in CLI, page, llms.txt, docs.
- **"Settings" does not exist.** The CLI says "Set a passphrase in the console under Settings"; the console nav has no Settings item (W/016 step 5, `W/016/screenshots/step-4.png`). The header sentence has a link `Set up` instead.
- **"Key needed · Not backed up"** chip: two states joined by a dot with a red dot. The user has not been told which is which, and the backup step is run by the agent. [S] A new user cannot tell whether this is an error.
- **"Workspace", "drive", "Operator console"** appear together in the console sidebar ("Personal workspace / OPERATOR CONSOLE", drive `Elena Codex`). Three nouns for the container on one screen (`W/006/screenshots/step-6-console.png`). Does a first-run user need "Operator console" at all? [S] Probably not.
- **"Access: Read, write, delete, share" / "Writes: Anywhere in the drive"** in Details (`W/018/screenshots/step-4.png`) is understandable; "Requested 11/27/2026, 6:04:28 PM" has no timezone (W/018 step 3). Minor.
- **Tag wording "Pairing request" / "Approval saved" / "Awaiting code" / "No pairing"**: the tag says "NO PAIRING" after an empty Continue click though nothing was looked up (W/017 step 2). Misleading.
- **Error for a wrong or expired code** lists three causes without telling which (W/017 step 4). The vowel-letters error is worse (W/017 step 3).
- **API URL**: `AGENT_DRIVE_API_URL` without `/api` returns "Agent Drive refused the login request: 404" (W/006, W/009, W/016). Local-origin only; production URL likely differs. Needs a check on prod before any claim. [S]
- **Naming drift web / CLI / docs**: "Connect an agent" (button), "Give this to your agent" (hero), "Give your first agent a home." (console onboarding panel, W/009 catalog) all describe the same action with three phrases. Low severity.

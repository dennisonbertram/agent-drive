# Judged improvement packages

These decisions apply the flow/walker evidence; alternatives were considered adversarially by the lead, not claimed as separate external-model votes. Five packages will be executed as five rounds on one branch/PR to avoid dependent unmerged PRs. No merge authorized.

| Round / area            | Evidence                                      | Alternatives and decision                                                                                                                                                                                                           | Safety boundary                                                                     |
| ----------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 1 File loading/recovery | W-001; baseline screenshot 26                 | A: only replace loading text, rejected: still no local recovery. B: explicit scope-bound failed state plus Retry, **chosen**. C: auto-retry indefinitely, rejected: hides outage and extra requests.                                | Preserve late-response cancellation and real empty onboarding; no backend changes   |
| 2 File filtering        | W-002; baseline 14/15                         | A: silently auto-fetch every page, rejected: unbounded work. B: clear no-match status, clear-filter action and loaded-only pagination hint, **chosen**. C: global search API, deferred: larger privacy/performance scope.           | Do not imply all remote files were searched                                         |
| 3 Spending controls     | W-003/004; baseline 35–37; lead mobile submit | A: scroll to existing global banner, rejected: leaves form behind. B: form-local error/success, focus error, human email guidance, **chosen**. C: live autosave, rejected: changes financial intent.                                | Preserve explicit save, server validation, blank/zero semantics and invoice warning |
| 4 Modal keyboard return | W-005                                         | A: suppress Escape, rejected: traps users. B: restore connected opener after close, **chosen**. C: replace native dialog library, rejected: disproportionate.                                                                       | Preserve busy/receipt dismissal guards and native modal behavior                    |
| 5 Mobile workspace menu | flow F4 and lead mobile screenshots           | A: seven always-visible wrapped tabs, rejected: consumes several permanent header rows. B: accessible labeled disclosure with all destinations, **chosen**. C: native select navigation, rejected: mixes in-page actions and links. | Desktop nav unchanged; mobile keyboard and active state remain clear                |

Deferred: full server-side search, card replacement for mobile tables, pricing restructuring, persistent drive-key storage, live-provider setup. These are not prerequisites to fixing the observed problems.

# Findings: account (billing, settings, sign-in, sign-up)

Inspector: ux-visual Phase 2, slug `account`. Session `ux-visual-account`, dev server http://localhost:3230, signed in as a synthetic user (`e2e_account_1`, no drives).
Shots: `docs/ux-visual/pages/account/shots/<viewport>-<state>[-full].png`. Metrics: `audit.json` (keys `<viewport>/<page>`). Second opinions: `second-opinion.json` (muse = meta/muse-wonder, argon = google/gemini-4-argon).

Also not seen: paid checkout, Stripe portal, a paid plan, a populated drive list for deletion, deletion requests with data, statement history. Settings was seen with zero drives; the "Delete one drive" form is therefore in its disabled state only.

## Excellent as is

- Billing metric cards, plan "UNIT 01/02/03" rack headers with the selected-unit black bar and orange LED dot: on-brand and consistent with the T1 reference.
- One orange primary per region on billing ("Save spending controls") with a hairline secondary elsewhere.
- Honest microcopy about estimates, taxes and delayed transfer reports.
- Danger zone: tinted panel, red left rule, typed confirmation, buttons disabled until valid, "When is data actually removed?" disclosure.
- Focus ring: clear 2px ink ring on every control; no page-level horizontal overflow at any viewport.
- Settings and billing tables use mono caps headers matching the console.

# /console Files, first-run audit (release 0.5.1 code, local http://localhost:3811)

Auditor method: brand-new account, Chrome via agent-browser, viewports 1440x900, 1280x800, 768x1024, 375x812.
Every state was captured at all four viewports (viewport and full page) in `shots/`; each file was opened and viewed.
layout-audit.js and geometry-audit.js results for every state x viewport are in `audit.json` (array of {state,width,layout,geometry}).
Screenshot names: `shots/<state>-<width>-view.png` and `-full.png`. Extra interaction shots: `02-*`, `04-*`, `06-*`, `14-*`, `15-*`, `16-passphrase-error-1440.png`.

## Run notes (read first)

- The assigned session `uxv-console-first-run` was being driven by another process at the same time (its page changed under me between commands: landing page, Create-a-drive dialog, then Agents). I switched to my own session `uxv-cfr-solo-7731` and account `e2e_vis_console_first_run_solo7732`. Nothing was killed.
- The shared scratchpad `cap.sh`/`ab.sh` were overwritten by a sibling agent. One of my calls ran the sibling's script and left 32 stray PNGs named like `1440 900-1280-view.png`, `375 812-375-full.png` in `../console-agents-keys/shots/` (and possibly entries in its `audit.json`). I tried to delete them; the auto-mode classifier refused. They are mine and should be removed by the owner of that page (`find ../console-agents-keys/shots -name '[0-9]* [0-9]*-*.png'`).
- Test data I created: one drive with a 200-character name (all "x") to test long input. It was accepted.
- The Next.js dev-tools badge overlaps "Local test session" bottom-left at every size. That is a dev-build artefact and is not scored.
- Not verified: the "Forget key" click (no confirm seen because I did not click it), real file download to disk, drag-and-drop of a recovery file, passphrase success path (I never completed Create with a valid passphrase).
- Heuristic IDs are from visual-heuristics.md. "measured" = from audit scripts or DOM numbers; "observed" = seen in a screenshot or interaction; "suspected" = inferred.

## Excellent as is

- Onboarding hero at 1440 and 1280: one orange primary (Copy), clear three-step line, secondary "New drive" visibly lower in weight, "Copied" feedback immediate. No page scroll and no horizontal overflow at any width (audit viewport.pageScrollX 0).
- Create a drive dialog: short copy, name field focused with text selected, 32px close, primary full width, fits at 375 (`shots/03-create-drive-dialog-375-view.png`).
- Key chip states use words plus shape and colour ("Key loaded" green, "Key needed" hollow, "Key loaded · Not backed up" red), not colour alone.
- Load-key dialog: Escape closes it and focus returns to the chip; drop zone and its focus ring are clear.
- Passphrase error: role=alert, plain message, both fields keep values.
- Workspace unavailable: recovery works and the panel is compact (about 190px), not a full-page void.
- Sidebar, breadcrumb and the 375 top bar collapse correctly (Files dropdown plus avatar) with no overflow.

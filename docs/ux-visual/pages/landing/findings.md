# Landing (/) findings

Inspector: own only (no second opinions). Signed-out session `ux-visual-landing`. Shots in `shots/` (prefix `{viewport}-home*`, `-scrollN`); metrics in `audit.json` (keys `1440x900-home`, `768x1024-home`, `390x844-home`; older `*-default-*` shots are from an earlier run).

## Verdicts

- 1440x900 home (`1440x900-home.png`, `-home-full.png`, `-scroll800..4300.png`): Strong marketing page. One clear focal point (80px headline), one orange primary (Copy) in a dark code panel, airy rhythm, hairline tables. Page is 5583px tall (about 6 screens), acceptable for marketing; no horizontal overflow, nothing offscreen. Weak spots: the nav has no sign-up path, and some sections carry uneven 3-column text.
- 768x1024 (`768x1024-home.png`): Reflows cleanly; nav intact. Hero diagram sits left-aligned in 492 of 704px.
- 390x844 (`390x844-home.png`, `-scroll*.png`): Reflows without overflow (pageOverflowX 0) but the header shows only the brand; Docs/Pricing/Sign in/Console are reachable only in the footer about 7800px down. Page is 7816px tall.

# console-files: /console Files view

Inspected 2026-11-04 against the shared dev server (localhost:3230), signed in with synthetic accounts, in agent-browser session `ux-visual-console-files`. Data: three drives (Billing agent: empty; Data pipeline staging: 2 files, key backed up; Research workspace: 10 files with long paths, emoji and CJK names, key not backed up). The free plan caps an account at 3 drives, so a 4th drive could not be created; "3+ drives" is covered with exactly 3 (see the overflow note under the findings). Screenshots are in `shots/<viewport>-<state>.png` (+ `-full.png`). Raw audit output is in `audit.json` (keyed viewport then state). Second opinions: `second-opinion.json` (muse-wonder, gemini-4-argon); every claim used below was checked against a screenshot or live DOM.

Evidence tags: measured (DOM/audit number), observed (seen in screenshot or live), suspected (not confirmed).

States captured: onboarding, empty-nokey, populated-nokey (backup warning shown), populated-keyloaded, backedup-nokey (backup warning hidden, replaced by "Key backed up" line), filter, loading (1440 and 375 only; the load is too fast to catch at the others, the markup is identical), plus 1440 extras: filter-nomatch, hover-row, plan-limit-dialog, and a 375 horizontally scrolled table.

## Excellent as is

- Drive bay strip concept: smoked-glass chips with an LED for the selected drive, name and size/file count; clear selected state and `aria-pressed`. Consistent with the T1 reference.
- Typography and palette on the main surface: Space Grotesk plus Plex Mono, aluminium ground, a single orange for LEDs and primary action; the file path with muted directory and bold file name is a good pattern (just truncate the other end).
- Empty and onboarding copy are friendly and specific ("Ready for your first file.", "Give your first agent a home.").
- Filter field is quick, case-insensitive and keeps focus; the `No loaded files match "x"` message echoes the query, including emoji.
- Focus ring and keyboard order are consistent and visible everywhere on this view.
- Table footer "File contents encrypted · Paths and metadata visible to the service" is honest, small print.

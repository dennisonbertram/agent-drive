# Brief: account pages
App: Agent Drive, portable encrypted storage for AI agents ("Every agent gets a drive"). T1 "Rack" design: aluminium grey ground, dot grid, black ink, one signal orange, Space Grotesk + IBM Plex Mono.
Pages: /console/billing (usage, plans, spend cap form, per-agent usage table), /console/settings (audit log, destructive deletion forms, deletion requests), /sign-in and /sign-up (Clerk not configured locally: only the fallback panel is visible).
Persona: a developer who runs AI agents and manages their workspace; checks spend, sets a write cap, may delete a drive or account.
States: billing free plan, paid checkout disabled, validation error; settings with no drives, audit log populated; auth fallback.
Viewports: 1440x900, 1920x1080, 768x1024, 375x812.

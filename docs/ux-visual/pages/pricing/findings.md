# Pricing (/pricing) visual audit, production, 2026-11-03

Shots in `shots/`, measures in `audit.json`. Second opinion: muse-wonder ran; gemini-4-argon failed to return for this page (`ok: false`), so only one external opinion. Known items (Manage your plan labels, 1024 GiB) excluded.

## Verdicts

- **1440x900** (`1440x900-default-1.png`, `-2.png`): well-structured three-card grid, readable. The hierarchy is wrong: the Free plan gets the only filled button while the highlighted Developer plan has none. The fine-print card is dense.
- **1920x1080** (`1920x1080-default-1.png`, `-2.png`): same layout in a 1128px container; fine, a large empty margin each side. Overage table visible without scrolling.
- **768x1024** (`768x1024-default-1.png`, `-2.png`): cards stay three-up, so bullets wrap with hanging lines ("5 GiB monthly / downloads included"). Acceptable but tight.
- **375x812** (`375x812-default-1.png` to `-5.png`): cards stack; page is 3022px tall; comparing plans requires scrolling and memory. No overflow. Last two screenshots are the same end-of-page position.
- Interaction (`1440x900-focus-tab3.png`): Tab order logo, Quickstart, Sign in, three plan CTAs; ring visible.

- Honest fine print about metadata visibility and recovery keys builds trust.
- No overflow at any viewport; focus ring visible; tab order matches reading order.
